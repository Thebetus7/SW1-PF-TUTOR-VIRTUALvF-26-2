1
Crear Grupo de Recursos en portal.azure.com
Un Grupo de Recursos es una carpeta virtual donde guardaremos la Máquina Virtual y su red.
  • 1. Entra a https://portal.azure.com con tu cuenta de Microsoft.
  • 2. En la barra de búsqueda escribe Grupos de recursos y haz clic.
  • 3. Clic en el botón + Crear.
  • 4. Nombre: rg-skylearn-prod. Región: (US) Este de EE. UU. (East US).
  • 5. Clic en Revisar y crear ➔ Crear.
2
Crear Máquina Virtual Linux (Ubuntu 24.04/22.04 LTS)
El servidor en la nube donde correrá Docker con PostgreSQL, Backend y Frontend Web.
  • 1. En el buscador escribe Máquinas virtuales ➔ + Crear ➔ Máquina virtual de Azure.
  • 2. Grupo de recursos: rg-skylearn-prod. Nombre de VM: vm-skylearn-prod.
  • 3. Imagen: Ubuntu Server 24.04 LTS (x64). Tamaño: Standard_B2s (2 vCPU, 4 GiB RAM) o Standard_B1ms.
  • 4. Autenticación: Contraseña ➔ Usuario: ubuntu y tu contraseña segura.
  • 5. Puertos de entrada públicos: Marca ☑️ SSH (22) y ☑️ HTTP (80).
  • 6. Clic en Revisar y crear ➔ Crear. Al terminar, anota la IP pública asignada.
3
Conectarte por SSH e Instalar Docker en 1 Solo Comando
Abre tu terminal en Windows (PowerShell) para conectarte al servidor y ejecutar el script oficial de Docker.
# 1. Conectarte a la máquina virtual ssh ubuntu@TU_IP_PUBLICA # 2. Instalar Docker y Docker Compose automáticamente curl -fsSL https://get.docker.com | sudo sh sudo usermod -aG docker $USER newgrp docker
4
Clonar el Repositorio y Levantar Todo el Stack
Con un solo comando de Docker Compose, se levanta PostgreSQL con volumen persistente, Backend NestJS con auto-migración y Frontend Nginx en puerto 80.
# 1. Clonar el repositorio git clone https://github.com/TU_USUARIO/TU_REPOSITORIO.git skylearn-prod cd skylearn-prod # 2. Configurar variables de entorno cp .env.prod.example .env # 3. LEVANTAR TODO EL STACK EN PRODUCCIÓN: docker compose -f docker-compose.prod.yml up --build -d
5
Verificar en Navegador y Conectar App Móvil
Todo el sistema responde por el puerto estándar 80 gracias a Nginx.
  • Frontend Web: Abre en tu navegador http://TU_IP_PUBLICA/ (Usuarios demo listos).
  • Swagger API Docs: Abre http://TU_IP_PUBLICA/api/docs.
  • App Móvil Docente: Corre en el teléfono; solo pon export const API_BASE_URL = 'http://TU_IP_PUBLICA/api/v1'; en frontend-mobile/src/services/api.ts.
6
Apagar y Reactivar la VM para Ahorrar Créditos
Detén la máquina cuando no la uses para pausar el cómputo a $0.00/hora. Al iniciarla, Docker levanta todo automáticamente sin comandos adicionales.
# Apagar la VM (Pausa facturación de cómputo): az vm deallocate --resource-group rg-skylearn-prod --name vm-skylearn-prod # Iniciar la VM (Los contenedores se levantan solos gracias a restart: unless-stopped): az vm start --resource-group rg-skylearn-prod --name vm-skylearn-prod
